# NEXUS — правила для правок

Сайт: статика на GitHub Pages + Supabase (проект dtlcqupalwrlcwyzrptq). `config.js` не трогать.

## Где что лежит
- `index.html` — разметка, подключение стилей и скриптов.
- `css/` — стили по разделам: `main.css` (общее), `vacation.css`, `book.css`, `slop.css`, `p51.css`, `places.css`.
- `js/` — код по разделам. Обычные скрипты без модулей, грузятся по порядку номеров и видят переменные друг друга. Порядок важен: файл может сразу при загрузке вызывать только то, что объявлено в нём или в файлах с меньшим номером. `17-boot.js` всегда последний.
- `sw.js` — service worker (офлайн и уведомления).
- `vendor/` — свои копии библиотек и шрифтов (Supabase, JSZip, MapLibre, Google Fonts), чтобы не зависеть от чужих CDN. Обновляются workflow «Библиотеки и шрифты к себе».
- `proxy.js` + `proxy/` — прокси к Supabase через Yandex Cloud Functions для России без VPN (см. `proxy/README.md`). Все обращения к адресу Supabase из кода — через `viaPx(...)` / `pxFetch`, не напрямую.
- `tests/` — автотест на подменной базе. Запуск: `npm i playwright && npx playwright install chromium && node tests/smoke.mjs`. Гоняется в GitHub Actions на каждый коммит.

## Версия файлов — обязательно
После любой правки в `js/` или `css/` подними номер `?v=` у всех подключений в `index.html` (и `VERSION` в `sw.js`), иначе у друзей смешаются старые и новые файлы.

## Патчноуты — обязательно
Любое изменение сайта сопровождается записью в массиве `PATCHES` в `js/07-patches.js` (если владелец не попросил без патчноута).
- Новая версия добавляется В НАЧАЛО массива: `{v: "1.8", date: "ГГГГ-ММ-ДД", title: "...", kind: "minor"|"major", sec: {n: [...], c: [...], f: [...], r: [...]}}`.
- `n` — новое, `c` — изменено, `f` — исправлено, `r` — удалено. Пишем по-русски, коротко, для игроков, без технических терминов.
- Мелкие правки в тот же день можно дописывать в текущую версию, крупные — новая версия. `major` — для больших фич.
- Сезон 0 (`season: 0`) — прототип в Claude, его не трогаем.

## Ошибки
Не глотать ошибки пустым `catch(e){}`. Неожиданные ошибки — в `logErr("где", e)` (пишется в таблицу `client_errors`, видно владельцу в «Ещё»). Пустой catch допустим только для ожидаемых случаев (localStorage в приватном режиме, браузер не дал включить звук) — с комментарием `/* ожидаемо: ... */`.

## Загрузка из базы
Supabase отдаёт максимум 1000 строк за запрос. Всё, что может вырасти больше, грузить через `fetchAll(...)` (пачками).

## Схема базы
Изменения базы дублируем в `schema.sql` (дописываем в конец, идемпотентно).

## Выкладка — по умолчанию сразу на сайт
Владелец хочет, чтобы правка сразу появлялась на сайте. После правки: прогони `node tests/smoke.mjs` (если есть playwright), затем коммит и `git push` в `main` — GitHub Pages обновит сайт примерно за минуту.
Если подключён браузер (Claude in Chrome), после выкладки открой https://abasowe945-dotcom.github.io/YONNER/ (обнови страницу), проверь, что правка видна и в консоли нет ошибок.
Не пушить, только если владелец сам сказал «не выкладывай» или «покажи сначала».
