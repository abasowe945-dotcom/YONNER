# NEXUS — правила для правок

Сайт: один файл `index.html` (GitHub Pages) + Supabase (проект dtlcqupalwrlcwyzrptq). `config.js` не трогать.

## Патчноуты — обязательно
Любое изменение сайта сопровождается записью в массиве `PATCHES` в `index.html` (раздел «патчноуты»).
- Новая версия добавляется В НАЧАЛО массива: `{v: "1.8", date: "ГГГГ-ММ-ДД", title: "...", kind: "minor"|"major", sec: {n: [...], c: [...], f: [...], r: [...]}}`.
- `n` — новое, `c` — изменено, `f` — исправлено, `r` — удалено. Пишем по-русски, коротко, для игроков, без технических терминов.
- Мелкие правки в тот же день можно дописывать в текущую версию, крупные — новая версия. `major` — для больших фич.
- Сезон 0 (`season: 0`) — прототип в Claude, его не трогаем.

## Схема базы
Изменения базы дублируем в `schema.sql` (дописываем в конец, идемпотентно).
