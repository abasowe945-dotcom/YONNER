# NEXUS — полка игр и кино для компании

Один сайт на всех. Каждый заходит под своей почтой, пишет свой ник и видит только свою библиотеку. Записи синхронизируются между компом и телефоном.

Всё бесплатно. Понадобятся два сервиса:
- **Supabase** — база, вход по почте и хранилище картинок.
- **GitHub Pages** — сам сайт.

Делается один раз, примерно за 30 минут.

---

## Шаг 1. База в Supabase

1. Зайди на **supabase.com**, нажми **Start your project** и войди через GitHub или почту.
2. **New project**:
   - Name: `nexus`.
   - Database Password: любой, сохрани его где-нибудь.
   - Region: ближайший к вам, например Frankfurt или Singapore.
   - Тариф: **Free**.
3. Подожди пару минут, пока проект создастся.
4. Слева открой **SQL Editor**, нажми **New query**, вставь **всё содержимое файла `schema.sql`** и нажми **Run**. Должно появиться `Success`.
5. Слева **Authentication → Sign In / Providers → Email**. Выключи **Confirm email** и сохрани. Так друзья будут входить сразу, без письма на почту.
6. Слева **Project Settings**:
   - **Data API** — скопируй **Project URL** (вида `https://abcd.supabase.co`).
   - **API Keys** — скопируй ключ **anon / public** (длинная строка, начинается с `eyJ`).

## Шаг 2. Вставь ключи

Открой файл **`config.js`** в любом редакторе (подойдёт Блокнот) и вставь оба значения вместо `ВСТАВЬ_СЮДА_...`. Кавычки оставь. Сохрани.

Ключ anon публичный, его нормально держать на сайте. Чужие библиотеки защищены правилами доступа в базе: каждый видит только своё.

## Шаг 3. Сайт на GitHub Pages

1. Зайди на **github.com** и создай аккаунт, если его нет.
2. Справа вверху **+ → New repository**:
   - Repository name: `nexus`.
   - **Public**.
   - Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file**. Перетащи **все файлы из этой папки**: `index.html`, `config.js`, `manifest.webmanifest`, иконки и остальное. Внизу нажми **Commit changes**.
4. В репозитории **Settings → Pages**:
   - Source: **Deploy from a branch**.
   - Branch: **main**, папка **/ (root)**.
   - Нажми **Save**.
5. Через 1–2 минуты сверху появится адрес сайта, вида `https://твойник.github.io/nexus/`.
6. Вернись в Supabase: **Authentication → URL Configuration**, в **Site URL** вставь этот адрес и сохрани.

Готово. Открываешь адрес, жмёшь **Создать аккаунт**, вводишь почту, пароль и ник.

## Друзьям

Скинь им ссылку на сайт. Каждый жмёт **Создать аккаунт**, пишет свой ник, и у него пустая полка.

**На айфон как приложение:** открыть ссылку в **Safari → Поделиться → На экран «Домой»**. Иконка откроет сайт на весь экран, без адресной строки.
**На Android:** в Chrome меню **⋮ → Добавить на главный экран**.

## Как обновлять сайт

Если я пришлю новый `index.html`: зайди в репозиторий, **Add file → Upload files**, перетащи новый файл поверх и нажми **Commit changes**. Через минуту обновится у всех. Данные не пропадут, они в базе, а не в файле.

## Полезно знать

- **Бесплатные лимиты Supabase:** 500 МБ под записи и 1 ГБ под картинки. Компании друзей хватит надолго.
- **Сон проекта:** если в проект неделю никто не заходил, бесплатный Supabase может его усыпить. Разбудить: зайти на supabase.com и нажать **Restore** у проекта. Данные не теряются.
- **Картинки:** обложки, обои и скриншоты хранятся по длинным случайным ссылкам. Найти их, не зная ссылки, нельзя, но по прямой ссылке картинку откроет кто угодно. Записи, оценки и заметки закрыты полностью.
- **Бэкап:** «Ещё → Профиль → Скачать бэкап» сохраняет все записи в файл. Обложки в него не входят.
- **Если на мобильном интернете не грузятся картинки или вход**, а на Wi-Fi всё работает, значит оператор режет доступ к Supabase. Это решается прокси через свой домен, напиши — сделаем.
